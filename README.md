## 二、内容简介

《艺术体验与审美鉴赏》是一本面向高校通识教育与美育课程的艺术鉴赏教材。
全书以"体验—鉴赏"为主线，先建立美学与艺术的基础理论框架，再分门类带领读者
进入各艺术门类的审美现场，强调在亲身感知与具体作品中培养鉴赏力，而非单纯记诵术语。

全书共八章，覆盖美学基础与七大类艺术形式：

1. **第一章 美学与艺术基础理论** —— 美的本质、艺术特征、中西美学差异等通论
2. **第二章 美术鉴赏** —— 绘画、雕塑等视觉艺术的中外发展脉络与名作赏析
3. **第三章 音乐体验与鉴赏** —— 中西方音乐史、乐器与乐曲的审美体验
4. **第四章 舞蹈体验与鉴赏** —— 舞蹈的起源、形态与代表性舞种
5. **第五章 戏剧体验与鉴赏** —— 中外戏剧传统与经典剧目
6. **第六章 戏曲体验与鉴赏** —— 中国戏曲的发展简史与剧种
7. **第七章 影视体验与鉴赏** —— 影视艺术源流与鉴赏方法
8. **第八章 书法体验与鉴赏** —— 书体演变、碑帖名作与笔法审美

每章末多配有"本章小结""思考题"等板块，便于复习与课堂讨论。
